# Autoencoder-based Semi-Supervised Learning from Tabular Data (SSLAE)

This repository contains the implementation of SSLAE, 
an autoencoder-based architecture for semi-supervised learning (SSL) from tabular data.

## Requirements

Built and tested with Python 3.10. All required libraries are listed in the `requirements.txt` file.

### SSLAE has a scikit-compatible implementation. Examples on how to use it can be found in the dummy_data_example.ipynb and openml_example.ipynb notebooks.
